# Dashboard fase 2

Esta es la fase 2/3 de la implementación ui de la página dashboard.

- Usa el screenshot indicado en la sección referencias para crear el diseño lo más parecido posible
- Usa los datos de @lib/mockdata.ts. Posteriormente usaremos una bd real.

## Requerimientos

- El menú de la izquierda debe ser collapsable.
- Un icono "Drawer" para abrir o cerrar la sidebar.
- En la vista mobile el icono Drawer estará presente por defecto
- En el menú deben aparecer los tipos de item con su respectivo color e icono.
- Debajo de los tipos de item se ubica la sección de colecciones debe ser desplegable con un icono >
- En la sección de colecciones deben aparecer las 3 últimas colecciones credadas, y un enlace a "view all"
- En la parte inferior del menú debe aparecer el usuario activo y su avatar.
